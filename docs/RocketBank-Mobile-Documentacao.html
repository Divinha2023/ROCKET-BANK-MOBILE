Rocket Bank Mobile

Aplicativo mobile de banco digital construído com Expo, React Native e TypeScript, com fluxos simulados de conta, cartões, Pix, investimentos, cashback e extrato.

Desenvolvido por: Divanildo Simões, Edoardo Famá, César Fraga e Djhonatah Wesley.

Contexto: Projeto desenvolvido durante a Academia de Java & I.A disponibilizada pela Accenture.

Versão: Documentação final do protótipo mobile.

1. Resumo executivo

O Rocket Bank Mobile é um protótipo funcional de banco digital que simula uma jornada bancária completa em ambiente mobile. O app foi desenhado para apresentar uma experiência moderna, visualmente consistente e orientada a interações financeiras comuns do dia a dia.

A aplicação permite que o usuário acesse a conta, consulte saldo, visualize cartões, pague faturas, envie Pix, simule investimentos, compre em parceiros, acompanhe cashback e consulte o extrato de movimentações. Todos os fluxos são locais e usam dados mockados, o que torna o projeto adequado para apresentação, estudo e evolução futura.

Objetivo principal: demonstrar domínio de construção de interfaces mobile com React Native, gerenciamento de estado local, organização modular do código e criação de fluxos financeiros simulados com boa experiência de uso.

2. Escopo do produto

Conta digital Consulta de saldo, rendimento, cashback e atalhos para operações frequentes.
Cartões e fatura Visualização de cartões, total da fatura e pagamento com reflexo no extrato.
Pix Transferência simulada com validação de saldo, valor e limite diário.
Investimentos Consulta de ativos, simulação de aplicação e atualização da carteira.
Shopping e cashback Compra simulada em parceiros com geração de cashback.

5. Fluxos funcionais

5.1 Inicialização

A aplicação inicia com uma tela de splash animada, reforçando a identidade visual do Rocket Bank antes de encaminhar o usuário para autenticação.

5.2 Login e cadastro

O login aceita e-mail ou CPF, senha e validações básicas. Também há fluxos de recuperação de acesso, cadastro simulado e login social demonstrativo.

5.3 Home

A tela principal mostra saldo, rendimento, cashback, atalhos rápidos, benefícios e últimas movimentações, funcionando como painel central da conta.

5.4 Cartões e fatura

O usuário visualiza cartões cadastrados, consulta fatura e simula pagamento. O pagamento debita o saldo da conta, gera cashback e registra as movimentações no extrato.

5.5 Pix

O fluxo de Pix valida valor, saldo disponível e limite diário. Após o envio, a transação é adicionada ao extrato.

5.6 Investimentos

A área de investimentos exibe ativos e permite simular uma aplicação, debitando o saldo e atualizando a carteira local.

5.7 Shopping e cashback

O Rocket Shopping apresenta produtos e parceiros, permitindo compras simuladas e geração de cashback para a conta.

6. Regras de negócio simuladas

Fluxo Regra aplicada
Pagamento de fatura Debita o saldo, marca a fatura como paga, registra saída e adiciona cashback de 3%.
Pix Impede valores inválidos, saldo insuficiente e envio acima do limite diário.
Investimentos Debita o saldo e adiciona o valor aplicado à carteira local do usuário.
Shopping Registra compra e adiciona cashback quando aplicável.
Extrato Recebe automaticamente eventos financeiros gerados pelos demais módulos.

7. Como executar o projeto

Instale as dependências:

npm install

Inicie o servidor Expo:

npm start

Escolha a plataforma desejada:

npm run android
npm run ios
npm run web

Para testar em um dispositivo físico, abra o Expo Go e leia o QR Code exibido no terminal.

8. Validação e qualidade

O projeto possui script de validação TypeScript para conferir tipagem e contratos básicos do código. 

npm run typecheck
Como o projeto ainda é um protótipo local, não há backend, banco de dados real ou autenticação remota. A próxima etapa natural seria incluir persistência, testes automatizados e integração com APIs simuladas.

9. Evoluções recomendadas

  • Implementar autenticação real com persistência segura de sessão.
  • Adicionar backend para contas, cartões, extrato, Pix e investimentos.
  • Persistir dados localmente para manter estado entre sessões.
  • Criar testes unitários para regras financeiras e componentes críticos.
  • Adicionar testes de fluxo para login, Pix, pagamento de fatura e investimentos.
  • Preparar builds mobile com EAS Build para distribuição controlada.
